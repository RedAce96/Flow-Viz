# Archived clean-break sources

These files document the retired global-switch, JSON-overlay, probe-v1, and
standalone analysis interfaces. They are not installed as current commands and
are retained only for provenance or numerical parity review.

Use the root `pelec_post.py`/`pelec-post` CLI, `compact_probes.py`, complete
YAML projects under `examples/`, and the tested package workflows for current
work. Legacy JSON and workflow flags are intentionally rejected.
